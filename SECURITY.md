# Security Policy

UTAMO OS is an experimental operating-system project for learning and OSDev
research. It is not intended for production use and does not currently provide
security guarantees. The current kernel runs in ring 0 without process or
userspace isolation.

Technical and security-related problems can be reported through
[GitHub Issues](https://github.com/zaureliu/UtamoOS/issues).
Include the version, environment, reproduction steps and relevant serial output.
Do not include credentials or other private information in a public report.

See the [release notes](docs/releases/v0.1.0.md) for known limitations.
